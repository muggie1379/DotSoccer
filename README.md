# DotSoccer Multiplayer Portfolio

반도체 장비 자동화 SW 엔지니어 경력(SECS/GEM, HSMS 통신 프로토콜 구현, 재연결/상태머신
처리)을 게임 서버 엔지니어링으로 연결하기 위한 포트폴리오 프로젝트. 미들웨어(Photon 등)
없이 TCP 소켓 서버를 직접 구현해 프로토콜 설계와 동시성 처리 역량을 보여주는 것이 목표.

그래픽/콘텐츠보다 서버 아키텍처가 핵심 평가 포인트다.

## 구조

- [`server/`](server/README.md) -- C++17, Linux epoll 기반 커스텀 TCP 서버.
  로비 -> 매치메이킹 -> 룸 생성 -> 게임 진행 -> 종료 흐름을 서버 권위 방식으로 처리한다.
- `client/` -- Unity(C#) 클라이언트. 입력 처리, 렌더링, 서버 상태 수신 후 보간만 담당한다.

## 로드맵

1. echo 서버 + 클라이언트 연결 (진행 중)
2. 로비 / 매치메이킹
3. 서버 권위 게임 로직 (틱 기반 상태 동기화)
4. 하트비트 기반 재연결 처리
5. 클라우드 배포 + 부하 테스트
6. 아키텍처 문서화
